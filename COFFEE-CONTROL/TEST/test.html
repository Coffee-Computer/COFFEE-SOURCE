POC: coffee.camera() — getUserMedia wrapper

Control methodology (summary)

Device primitives — One API surface for camera, mic, location, clipboard, share, speech, encryption. Wraps browser APIs that need permissions.
Singleton — Single coffee object. No constructors, no new. Call coffee.camera(), coffee.speak() directly.
Bricks not schematics — Primitives you combine. No framework, no bloat. Vanilla JS only.
Permission-first — Camera, mic, geolocation, notifications require user consent. Handle denials gracefully.
Sovereign — No external runtime. Works standalone. Pair with Coffee UI for full-stack bricks.
