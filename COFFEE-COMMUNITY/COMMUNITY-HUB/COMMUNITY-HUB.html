Quick Start Guide

Welcome to the Coffee.SDK. To begin interacting with the bean-chain, you first need to initialize your environment. Ensure you have Node.js 18+ installed.

npm install @coffee/sdk

Initial Setup

// Initialize the roast engine
import { Coffee } from '@coffee/sdk';

const engine = new Coffee({
  temp: 92,
  bean: 'ETH_ROAST_01'
});

await engine.ignite();
