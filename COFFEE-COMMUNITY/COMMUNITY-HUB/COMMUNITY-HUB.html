Overview

COFFEE-SOURCE is a modular monorepo: many top-level COFFEE-* directories, each focused on a domain (UI, Play, Drive, Community, and so on). The COFFEE-COMMUNITY/ tree is the Community Edition umbrella (shells, registries, flagship α HTML, CCE tooling). Every package usually ships its own README.md for usage and development notes.

Clone & layout

Clone the repository, then open the module you care about. There is no single npm @coffee/sdk install in this tree—the integration surface is the source layout and per-module docs.

git clone https://github.com/Coffee-Computer/COFFEE-SOURCE.git
cd COFFEE-SOURCE

Flagship Community pages (homescreen, shell, hub, store) load JSON and modules via relative URLs. Serve the repo root over HTTP so fetches and links resolve—for example:

python3 -m http.server 8080
# Hub: /COFFEE-COMMUNITY/COMMUNITY-HUB/COMMUNITY-HUB.html

Edition status

High-level status—including the Community Edition freeze (baseline as of March 2026), what “frozen” means, and how the rest of the monorepo may still evolve—is documented in SOURCE-STATUS.md. A deeper snapshot (modules, shell apps, CCE-oriented APIs, file layout) lives in COMMUNITY-STATUS.md.

CCE packages & install API

The .cce archive format, manifest rules, inline cce:* meta tags, and strict validator expectations are specified in CCE-SPEC.md. Persisting validated apps into Drive and merging installed tiles with curated grids is covered in COFFEE-INSTALL/README.md (coffee.install API).
