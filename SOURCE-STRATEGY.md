# COFFEE Source Strategy

## Two Products, One Ecosystem

- **coffee-os** — The real deal. The product. Polished, premium, consumer-facing. Built with production-grade tools (Tailwind, etc.). This is what you sell.
- **coffee-source** — High-end dev tool. The new React/Next. Open source, rough around the edges, built for builders. Fast and durable. Infra is green.

## Status

Source infra = green. Ready for dogfooding. OS = the real deal.

## Audience Split

| | coffee-source | coffee-os |
|---|---|---|
| **Audience** | Devs, people who will actually build with it | Consumers who want super easy |
| **Apps** | Examples, demos, patterns — "here's how you build" | The real product — "here's what you use" |
| **Vibe** | Hiking boots: rough, fast, durable, meant to be used | Jordans: lux, polished, premium |

## Monetization

- **Source is free.** Don't feel bad about it. You're not making money from the framework directly.
- **OS is paid.** That's where revenue lives. Hosting, premium features, the product.
- **Chrome / Chromium play:** Open source = platform capture. Usage, adoption, ecosystem. The scoop.
- **Google play:** Firebase, AI Studio free. Cloud, scale, pro tooling paid. Give enough to be useful, charge for what adds value.

## Dogfooding Phase

Source is very DIY right now. That's intentional. Everything is connected in one place — gives time to dogfood and improve before it goes public. The roughness is useful; you can change things as you learn. No pressure to ship polished yet.

## Open Source Split

When ready: extract COFFEE-SOURCE into its own public repo. coffee-os stays closed. Clean cut. Source is already standalone (control moved in). You own both platforms. Iframe from OS to showcase source — clean divide.

## Source → OS Pipeline

Cook fire in source → port to OS. Source is the proving ground; when something hits, polish it and ship it on the OS. Build in the rough, ship in the lux.

## Acquisition Angle

Usage → adoption → standard → acquirable. Source becomes "a real tool" in the ecosystem, not just a personal project. Legitimate, adoptable.
