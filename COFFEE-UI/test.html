Coffee UI

High-value primitives + layout helpers. No Tailwind, no externals.

Design principles (summary)

Fixed shell, flexible content — Header and footer fixed; main area flex-grows. Max-width 600px for comfortable reading on desktop.
Touch-first — Min 44×44px tap targets for buttons and interactive elements.
No alert() — Use coffee.msg() for success, warning, error feedback.
Loading states — Show coffee.spinner() before fetch; never leave users guessing.
Visual consistency — One or two main colors, clean typography (Inter/system-ui), shadows and rounded corners.
